# 蛟龙模式查看器 1.0

双击 **蛟龙模式查看器.exe**，允许 Windows 管理员权限提示，即可查看当前模式。无需安装，也不需要运行之前的“蛟龙轻控”。程序未签名。

从仓库的 [Releases](https://github.com/incointo/jiaolong-mode-viewer/releases) 页面下载 EXE；源码仓库不保存编译产物。

- 显示办公、游戏（均衡）、狂暴、自定义或未知模式。
- 每 2 秒刷新，也可点“立即刷新”；关闭窗口即退出，没有托盘残留或开机启动项。
- 读取失败立即显示“无法确认”，不会继续将旧模式当作当前状态。
- 使用 Windows 原生窗口，不依赖 WebView2；使用系统 .NET Framework。

## 适用范围

仅针对本次已核查的机械革命蛟龙 16K：MECHREVO / GM6BGEQ / BIOS N.1.05MRO02。机型或 BIOS 不匹配时拒绝读取，不猜测模式。必须保留已安装的原厂 ACPI 驱动；本程序不附带、不安装驱动。

## 读取方式与限制

通过原厂 `\\.\ACPIDriver` 设备调用 EC **读取**指令 `2621482120`，仅访问地址 `0x0751` 和 `0x0726`。驱动要求以管理员身份、按原厂方式打开设备句柄，但程序没有硬件写入指令。

先判断 `0x0726 & 0x80`：置位时显示自定义模式；否则用 `0x0751 & 0x90` 解析：`0x80` 为办公，`0x00` 为游戏，`0x10` 为狂暴，其余为未知。每次重复读取两组数据，不一致时本次不确认，等待下次刷新。

显示的是硬件模式标志，并不证明 CPU/GPU 实际功耗达到某个数值，也不保证整套风扇和显卡参数已全部应用。本程序不查看或改变原厂服务，不切换模式，不上传风扇曲线，不修改系统、注册表或原厂文件。可与原厂后台同时运行。

## 源码与构建

`src/` 为完整 C# 源码，`tests/` 为检查程序。运行 `build.ps1` 使用 Windows 自带 .NET Framework C# 编译器，生成 64 位 EXE，无需下载依赖。源代码及构建脚本均包含在完整包中。

`--diagnose` 参数运行一次真实只读检查后退出。该诊断输出需通过重定向捕获；普通双击直接显示窗口。
